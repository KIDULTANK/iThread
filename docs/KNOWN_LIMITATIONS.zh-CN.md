# iThread v0.1.1 已知限制

这是公开预览版本，适合用备份文件体验和反馈，不建议作为重要资料的唯一存储位置。

## iThoughts 兼容性

- `.itmz` 当前只支持导入，不能导出或覆盖写回。
- 导入后请保存为 `.mmst`；iThoughts 无法直接打开 `.mmst`。
- 主题层级、文字、备注、链接、折叠状态、关系和部分图片可以导入；个别样式、字体、
  位置、附件或 iThoughts 专有元数据可能不能完整保留。
- 如需继续在 iThoughts 中编辑，请保留原始 `.itmz`。可尝试通过 `.mm` 或 `.opml` 交换，
  但这不是无损往返。

## Windows 发布

- 当前只提供 Windows 11 x64 便携版。
- SignPath 开源代码签名申请正在审核，当前文件尚未签名，SmartScreen 可能显示警告。
- 应用暂不提供自动更新；请从项目的 GitHub Releases 页面获取新版本。

## 数据和同步

- 无账号、无遥测，地图默认保存在本机。
- 尚无云同步；请自行备份 `.mmst` 或 `.json` 文件。
- 浏览器版本的数据位于对应浏览器的本地存储中，清理浏览器数据可能一并删除未导出的地图。

## 反馈边界

公开提交问题前请先将导图脱敏。不要上传身份证件、客户信息、案件材料、商业秘密或其他敏感内容。
