# iThread 下一版本已知限制

这是公开预览版本，适合用备份文件体验和反馈，不建议作为重要资料的唯一存储位置。

## iThoughts 兼容性

- `.itmz` 支持导入，也可导出为 iThoughts 兼容的新文件；为保护数据，不会覆盖原始 `.itmz`。
- 日常编辑请保存为 `.ithread`；iThoughts 不认识该原生格式，需要通过“导出 → `.itmz`”交换。
- 旧版 iThread 的 `.mmst` 文件仍可无损打开，但新保存文件默认使用 `.ithread`。
- 主题层级、文字、备注、链接、折叠状态、关系和部分图片可以导入；个别样式、字体、
  位置、附件或 iThoughts 专有元数据可能不能完整保留。
- 导出的 `.itmz` 已通过五份真实文件、31,389 个主题的结构往返测试，并已在原版 iThoughts
  中完成实际打开验证。iThoughts 专有样式、摘要、边界、少见图标或元数据仍可能降级，
  重要文件仍建议保留原件并抽查关键内容。
- 导出 `.itmz` 前会先显示兼容性报告，逐项说明保留、转换或无法带回 iThoughts 的内容；
  该报告用于知情确认，不代表所有第三方版本都能完全一致地显示。

## Windows 发布

- Windows 11 x64 同时提供安装版和便携版。安装版可注册 `.ithread`、`.mmst`、`.itmz`
  文件关联；便携版本身不会修改系统文件关联。
- SignPath 开源代码签名申请正在审核，当前文件尚未签名，SmartScreen 可能显示警告。
- 桌面版可以手动检查 GitHub Releases 更新，并由用户决定是否打开下载页面；不会静默下载
  或安装新版本。

## 数据和同步

- 无账号、无遥测，地图默认保存在本机。
- 本地自动保存之外另有短间隔恢复草稿；若应用异常退出且恢复草稿比稳定存档新，下次启动会
  询问恢复或丢弃。磁盘损坏仍可能同时破坏两者，因此它不能代替外部备份。
- 尚无 iThread 自建账号云。可把原生 `.ithread` 文件保存在 OneDrive、Dropbox、坚果云等
  系统同步目录；桌面版会直接回存已绑定文件，并在检测到外部更新时暂停静默覆盖、要求用户
  确认。跨设备同时编辑同一文件仍可能产生同步服务自己的冲突副本。
- 浏览器版本的数据位于对应浏览器的本地存储中，清理浏览器数据可能一并删除未导出的地图。

## 反馈边界

公开提交问题前请先将导图脱敏。不要上传身份证件、客户信息、案件材料、商业秘密或其他敏感内容。
