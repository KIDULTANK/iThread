# iThread v0.7.1 · 焦点与自动缩放 / Focus and Auto Zoom

**[简体中文](#简体中文) | [English](#english)**

## 简体中文

- **视图 → 焦点模式**（`Alt+Shift+F`）：未选中主题时开启，焦点跟随选择；先选中一个或多个主题再开启，锁定这些分支。其他分支只淡化。可在画布上方切换，按 `Esc` 退出。
- **视图 → 自动缩放**（`Alt+Shift+Z`）：平滑居中并适配选区，上限 125%；编辑、拖动和框选时暂停。手动平移或缩放后，下次换选区再跟随。
- Windows 版改进了原生打开文件、首次保存、窗口位置恢复及更新筛选。
- Windows 下载提供安装版和便携版，均为预览构建。安装包尚未代码签名。
- 华为测试包使用独立应用标识，可和旧测试包并存；要转移旧文件库里的导图，请先导出 `.ithread` 再导入。该包仍需华为实机验证。

[iThoughts 功能差距盘点](https://github.com/KIDULTANK/iThread/blob/v0.7.1/docs/ithoughts-feature-audit.md)

## English

- **View → Focus mode** (`Alt+Shift+F`): enable it with no topics selected to follow your selection, or select topics first to lock their branches. Other branches stay visible but dimmed. Use the banner to switch modes, or press `Esc` to exit.
- **View → Auto zoom** (`Alt+Shift+Z`): smoothly center and fit the selection, up to 125%. Editing, dragging and marquee selection pause the camera. Manual panning or zooming holds the view until the next selection.
- The Windows preview improves native file opening, first save, window placement and Windows update filtering.
- Windows installer and portable downloads are unsigned preview builds.
- The Huawei test APK installs alongside the previous test. Export and import `.ithread` files to move maps between them. Huawei hardware validation is still pending.
