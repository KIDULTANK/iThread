# iThread v0.3.0

这是一次面向大型导图流畅度的公开预览更新。

## 主要变化

- 大图连线绕障碍改用空间索引，避免主题数量增加时反复扫描整张导图。
- 超过 600 个可见主题时自动跳过整图逐帧动画，小范围展开仍保留平滑过渡。
- 五份真实 iThoughts 文件已加入本机性能基准，共 31,389 个主题；最大单文件 11,859 个主题
  完全展开并完成布局约需 0.88 秒（同机测试，仅用于版本间对比）。
- 确认 iThread 导出的 `.itmz` 已能由原版 iThoughts 实际打开。

## 下载与校验

下载 `iThread-0.3.0-Windows-x64.exe` 与同页的 `SHA256SUMS.txt`。当前构建仍可能尚未完成
代码签名，Windows SmartScreen 出现提示时，请先核对 SHA-256。

日常编辑建议保存为 `.ithread`；需要与 iThoughts 交换时，再通过“导出”生成新的 `.itmz`，
不要覆盖唯一的原文件。
