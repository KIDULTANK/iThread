# iThread v0.2.0

这是一次文件兼容性升级，重点解决“iThread 编辑结果如何继续交给 iThoughts 使用”。

## 主要变化

- 新增 iThoughts 兼容 `.itmz` 导出：导出菜单选择 `.itmz（兼容 iThoughts）`，即可生成
  新文件，不会覆盖原始 `.itmz`。
- `.itmz` 导出包含主题层级、文字、备注、链接、折叠状态、任务优先级与进度、关系线、
  浮动主题以及可用的内嵌图片。
- iThread 原生文件扩展名改为 `.ithread`，用于日常无损编辑、保存和自动保存。
- 旧 `.mmst` 和 `.json` 文件仍可无损打开，不需要手动转换；再次另存时默认使用
  `.ithread`。
- 文件菜单已明确区分“保存 iThread 文件”和“导出 iThoughts 兼容文件”，减少格式误解。

## 真实格式验证

使用 5 份真实 iThoughts 7.25 文件完成导入→导出→再次导入测试，共覆盖 31,389 个主题，
包括折叠分支、图片、浮动主题和关系线。原始测试文件均只读，未被覆盖。

## 使用建议

- 日常编辑和备份：使用 `.ithread`。
- 需要在 iThoughts 中继续编辑：使用“导出 → `.itmz（兼容 iThoughts）`”。
- 首次交换重要文件时，请在原版 iThoughts 中复核少见样式、图标、摘要、边界和专有元数据。
- 本版本仍是公开预览版，Windows 构建如未签名，SmartScreen 可能显示“未知发布者”；请
  从本项目 Releases 下载并核对 `SHA256SUMS.txt`。
