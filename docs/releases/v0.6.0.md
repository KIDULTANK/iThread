# iThread v0.6.0

这一版只增强本地 CLI 控制桥，不加入 AI 助手、模型接口或账号系统。

## 正式 Windows 版 CLI

- 安装版和便携版运行时都会启动仅限本机的 CLI 控制桥；不再要求浏览器开发预览。
- 每次启动随机选择回环端口并生成新的 256 位访问令牌。CLI 从当前用户的应用数据目录自动
  发现连接；令牌不进入导图页面，带浏览器来源的请求会被拒绝。
- `status` 返回协议版本、连接方式和功能清单。队列有数量、体积和过期限制，CLI 或端口异常
  不会影响编辑器正常启动。

## 面向自动化的命令

- 新增 `open`、`export`，以及通过标准输入直接导入 Markdown。
- 新增 `batch`：最多 10,000 项新增、改名、移动和明确删除操作只复制一次文档、保存一次，
  并作为一次操作进入撤销历史。任何一项失败，整批内容都不会写入。
- `batch --dry-run` 可在保存前验证完整计划并返回预期结构统计。
- 普通修改默认返回紧凑结果，避免大型导图在 CLI 中反复传输；需要完整文档时可显式使用
  `--include-map`。

## 分发

Windows 包内附 `ithread-cli.cmd` 和 `ithread-cli.mjs`，GitHub Release 也单独提供。CLI 启动器
需要 Node.js 18 或更高版本；软件本身仍不依赖 Node.js 才能编辑导图。

安装版文件名为 `iThread-0.6.0-Windows-x64-Setup.exe`，便携版为
`iThread-0.6.0-Windows-x64-Portable.exe`。当前构建在代码签名完成前仍可能触发 SmartScreen，
请从项目 Releases 页面下载并核对同页 `SHA256SUMS.txt`。
