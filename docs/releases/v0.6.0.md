# iThread v0.6.0

**[简体中文](#简体中文) | [English](#english)**

## 简体中文

这一版只增强本地 CLI 控制桥，不加入 AI 助手、模型接口或账号系统。

## 正式 Windows 版 CLI

- 安装版和便携版运行时都会启动仅限本机的 CLI 控制桥；不再要求浏览器开发预览。
- 每次启动随机选择回环端口并生成新的 256 位访问令牌。CLI 从当前用户的应用数据目录自动
  发现连接；令牌不进入导图页面，带浏览器来源的请求会被拒绝。
- `status` 返回协议版本、连接方式和功能清单。队列有数量、体积和过期限制，CLI 或端口异常
  不会影响编辑器正常启动。

## 面向自动化的命令

- 新增 `open`、`export`，以及通过标准输入直接导入 Markdown。
- 新增 `batch`：最多 10,000 项新增、改名、移动和明确删除操作只复制一次文档、保存一次，
  并作为一次操作进入撤销历史。任何一项失败，整批内容都不会写入。
- `batch --dry-run` 可在保存前验证完整计划并返回预期结构统计。
- 普通修改默认返回紧凑结果，避免大型导图在 CLI 中反复传输；需要完整文档时可显式使用
  `--include-map`。

## 分发

Windows 包内附 `ithread-cli.cmd` 和 `ithread-cli.mjs`，GitHub Release 也单独提供。CLI 启动器
需要 Node.js 18 或更高版本；软件本身仍不依赖 Node.js 才能编辑导图。

安装版文件名为 `iThread-0.6.0-Windows-x64-Setup.exe`，便携版为
`iThread-0.6.0-Windows-x64-Portable.exe`。当前构建在代码签名完成前仍可能触发 SmartScreen，
请从项目 Releases 页面下载并核对同页 `SHA256SUMS.txt`。

## English

This release focuses exclusively on the local CLI control bridge. It does not add a built-in AI
assistant, model provider, API key screen or account system.

### Production Windows CLI bridge

- The installer and portable application now start a loopback-only CLI bridge; a development browser
  preview is no longer required.
- Each launch selects a random local port and creates a new 256-bit access token. The CLI discovers
  the connection from the current user's application data directory. The token is never exposed to
  map content, and requests carrying a browser Origin are rejected.
- `status` reports the protocol version, transport and supported capabilities. Queue length, payload
  size and result lifetime are bounded so CLI failures cannot block the editor from starting.

### Automation commands

- Added `open`, `export`, and direct Markdown import through standard input.
- Added `batch`: up to 10,000 add, rename, move or explicitly confirmed delete operations are cloned
  once, saved once and recorded as one undo step. If any operation fails, none of the batch is saved.
- `batch --dry-run` validates the complete plan and returns expected structure statistics without
  saving.
- Mutations return compact results by default to avoid retransmitting large maps. Use `--include-map`
  when the full document is required.

### Distribution

Windows packages include `ithread-cli.cmd` and `ithread-cli.mjs`, and both are also available as
separate release assets. The CLI launcher requires Node.js 18 or newer; the application itself does
not require Node.js for normal map editing.

The installer is `iThread-0.6.0-Windows-x64-Setup.exe`; the portable build is
`iThread-0.6.0-Windows-x64-Portable.exe`. The current build may trigger SmartScreen until code signing
is active. Download only from Releases and verify the adjacent `SHA256SUMS.txt` file.
