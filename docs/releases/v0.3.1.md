# iThread v0.3.1

这是一次继续面向大型 iThoughts 文件响应速度的公开预览更新。

## 主要变化

- 512 KiB 及以上的 `.itmz` 文件改由后台线程解析，导入期间主界面仍可响应鼠标、键盘和绘制。
- 展开、收起或按数字键调整单个分支层级时，只复制实际变化的分支路径，不再复制整份导图。
- 未变化分支的任务进度汇总结果会被复用，避免每次展开都遍历所有隐藏主题。
- 导入时增加中文和英文状态提示。

## 真实文件基准

五份真实 iThoughts 文件共 31,389 个主题。11,859 主题的《民法》导图中，单分支模型更新
约 0.03 ms，包含 19 个可见主题的分支布局约 8.3 ms；完全展开布局约 456.9 ms。
数据只用于同一测试机器上的版本对比，源文件没有上传或修改。

## 下载与校验

下载 `iThread-0.3.1-Windows-x64.exe` 与同页的 `SHA256SUMS.txt`。当前构建仍可能尚未完成
代码签名；Windows SmartScreen 出现提示时，请先核对 SHA-256。

日常编辑建议保存为 `.ithread`。需要与 iThoughts 交换时，再通过“导出”生成新的 `.itmz`，
并始终保留原始文件。
