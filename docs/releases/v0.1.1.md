# iThread v0.1.1 公开预览版

这是面向 iThoughts 同好的 Windows 11 公开测试版。建议先用备份文件体验，不要将唯一份重要导图交给任何预览版软件。

## 这个版本包含

- Windows 11 x64 便携版，无需安装。
- iThoughts `.itmz` 实文件导入与基本格式还原。
- 向右展开布局、中英文界面、长按 Alt 查看快捷键。
- 字体与字号调整、本地优先存储、CLI 自动化接口。
- 构建流水线同时发布 `SHA256SUMS.txt`，用于核对下载文件。

## 重要限制

- `.itmz` 目前只能导入，**不能将修改回写或导出为 iThoughts 可再次打开的 `.itmz`**。
- 继续编辑请保存为 iThread 原生 `.mmst`，并始终保留原始 `.itmz`。
- 当前安装包尚未代码签名；SignPath Foundation 开源签名申请审核中。Windows SmartScreen 可能显示提醒。
- 部分 iThoughts 专有属性可能无法完整还原。完整清单见 [已知限制](../KNOWN_LIMITATIONS.zh-CN.md)。

## 下载后校验

在 PowerShell 中运行：

```powershell
Get-FileHash .\iThread-0.1.1-Windows-x64.exe -Algorithm SHA256
```

结果应与本 Release 附件中 `SHA256SUMS.txt` 的值完全一致。
