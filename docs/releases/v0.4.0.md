# iThread v0.4.0

这一版继续优化完全展开大型导图时的响应，并加固本地自动保存。

## 主要变化

- 可见主题达到 600 个时，主题投影、整图布局和连线几何改在后台线程中计算。计算期间界面
  可以继续响应，完成后再一次性更新画布。
- 连续编辑会取消已经过时的后台布局，并校验结果代次，较慢的旧计算不会覆盖较新的编辑。
- IndexedDB 本地保存改为严格排队，避免较早的慢写入晚于新写入完成而把旧内容盖回去。
- 尚在 500 ms 自动保存等待期内的修改，会在窗口隐藏或关闭时立即进入保存队列。

## 兼容性与数据

`.ithread`、旧 `.mmst` 及 `.itmz` 导入/导出行为不变。大型布局不改变文件内容和坐标规则；
不支持 Web Worker 的环境会自动使用原来的同步计算路径。

自动保存仍是本地优先、无需账号。突然断电或操作系统强制结束进程时，最后极短时间内的修改
仍可能来不及写入，因此重要资料仍应定期导出 `.ithread` 备份。

## 下载与校验

下载 `iThread-0.4.0-Windows-x64.exe` 与同页的 `SHA256SUMS.txt`。当前构建仍可能尚未完成
代码签名；Windows SmartScreen 出现提示时，请先核对 SHA-256。
