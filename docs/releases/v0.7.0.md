# iThread v0.7.0

**[简体中文](#简体中文) | [English](#english)**

## 简体中文

本次公开预览版将可选的多设备手动同步加入 Windows 安装版和便携版。同步仍为实验功能，
不影响离线使用，不需要注册 iThread 账号，默认不会上传任何导图。

### 更新内容

- “设置 → 多设备同步”：填写自己的 WebDAV 专用目录及应用凭据，选择导图后手动同步。
- Windows 桌面版可直接连接坚果云；使用用户自己的网盘空间和流量。
- 坚果云每次变化写成独立历史版本；并发修改保留双方，不以修改时间决定覆盖。
- 查找远端导图、同步基准和冲突持久化、替换前版本备份、删除标记及可恢复回收站。
- 密码仅留在本次设置会话的内存中，不加入导图、导出文件或发布包。
- 保留现有界面、图标、模板库、中英文切换、离线编辑、`.itmz` 兼容和本地 CLI。

### 重要限制

- 2026-10-15 的真实坚果云测试使用两个独立模拟客户端，六项场景通过；
  尚未完成两台实际电脑的界面级验证，本次发布没有新增人工实测。
- 仅手动同步所选导图；正在编辑的导图及恢复草稿会暂缓处理。请先回到文件库再同步。
- 冲突双方可下载为 JSON 核对包，尚无一键合并；没有后台自动重试或端到端加密。
- 坚果云历史上限：每图 256 个版本 / 累计 128 MiB，目录最多发现 4096 个文件。
  不自动清理历史，达到上限会停止同步；不要把同步当作唯一备份。
- 网页版不能直接连接坚果云；其他 WebDAV 服务仍需兼容条件写入和浏览器跨域访问。
- Mac、iPad 和安卓客户端尚未提供；旧协议文件不会自动迁移。

### 下载与升级

- 安装版：`iThread-0.7.0-Windows-x64-Setup.exe`
- 便携版：`iThread-0.7.0-Windows-x64-Portable.exe`
- 同时提供独立 CLI 启动器及 `SHA256SUMS.txt`。

升级前请导出重要导图备份并关闭旧版。安装版沿用原有应用数据；不会自动导入此前独立
同步测试版的数据，如需迁移，请先从测试版导出 `.ithread` 再在新版导入。
不要删除应用数据目录。当前构建未代码签名，SmartScreen 可能提示“未知发布者”；
仅从本仓库 Releases 下载并核对 SHA-256。

配置方法及完整限制：[中文同步指南](https://github.com/KIDULTANK/iThread/blob/v0.7.0/docs/SYNC.zh-CN.md)。

## English

This public preview brings optional manual device sync to the Windows installer and portable builds.
Sync remains experimental. Offline editing needs no account, and no maps upload automatically.

### What's new

- **Settings → Device sync**: configure your own dedicated WebDAV directory and application credentials,
  select maps and sync manually.
- A restricted native Windows connection for Nutstore, using your own storage and traffic quota.
- Immutable Nutstore history revisions retain divergent changes instead of choosing a last writer.
- Remote-map discovery, persistent baselines and conflict copies, pre-replacement history backups,
  versioned tombstones and recoverable Trash.
- Passwords stay in memory for the Settings session, not in maps, exports or release packages.
- Existing UI, icon, templates, bilingual interface, offline editing, `.itmz` compatibility and CLI remain.

### Important limitations

- Six real Nutstore scenarios passed on 2026-10-15 using independently simulated clients, not two
  physical computers. Two-device UI validation remains outstanding; no additional manual testing
  was performed for this release.
- Sync is manual and opt-in per map. Active editors and recovery drafts are deferred; return to the
  library before syncing.
- Conflicts can be downloaded as JSON review bundles, but there is no one-click merge, automatic
  background retry or end-to-end encryption.
- Nutstore history is capped at 256 revisions / 128 MiB per map and 4096 discovered directory entries.
  History is not automatically pruned; reaching a cap stops sync. Keep independent backups.
- The web app cannot connect directly to Nutstore. Other WebDAV providers need compatible conditional
  writes and browser CORS support. Legacy sync files are not automatically migrated.
- Mac, iPad and Android clients are not available.

### Download and upgrade

- Installer: `iThread-0.7.0-Windows-x64-Setup.exe`
- Portable: `iThread-0.7.0-Windows-x64-Portable.exe`
- Standalone CLI launchers and `SHA256SUMS.txt` are included.

Export backups and close the old version before upgrading. The installer keeps the existing app data;
it does not automatically import the separate sync test-build profile. Export `.ithread` maps from
that test build and import them into this version if needed. Do not delete the application data directory.
Windows builds remain unsigned and may trigger SmartScreen's “Unknown publisher” warning. Download
only from this repository's Releases and verify SHA-256.

See the [English sync guide](https://github.com/KIDULTANK/iThread/blob/v0.7.0/docs/SYNC.en.md).
