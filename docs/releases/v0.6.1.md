# iThread v0.6.1

**[简体中文](#简体中文) | [English](#english)**

## 简体中文

本次更新将最近的界面、图标、设置和语言适配改进带入 Windows 安装版与便携版。

- 更新应用界面与朱红印章式图标，统一首页、编辑器及 Windows 应用图标。
- 模板和示例合并为一个“模板库”，分为待填写的“结构模板”和填好内容的“完整示例”。
- 文件库左侧导航栏增加设置入口，编辑器也可通过齿轮或 `Ctrl+,` 打开设置。
- 设置可调整外观、动画、高对比度、Alt 长按提示与等待时间、滚轮平移／缩放及速度。
- 修复长按 Alt 显示快捷键列表时，左右方向键误触发分支移动并关闭列表的问题。
- 首次启动跟随 Windows 首选系统语言：中文默认简体中文，其他语言默认英文；手动选择
  会保存并优先于自动识别。网页版按浏览器语言偏好选择，不使用 IP 定位。
- 更新中英文“关于”，补齐 iThread 维护者与上游来源说明。
- 保留离线编辑、`.ithread` 原生保存、iThoughts `.itmz` 导入导出和本地 CLI 自动化能力。

### 下载与升级

下载安装版 `iThread-0.6.1-Windows-x64-Setup.exe`，或便携版
`iThread-0.6.1-Windows-x64-Portable.exe`。另附 CLI 启动器和 `SHA256SUMS.txt` 校验值。
升级前请备份重要导图；请勿删除应用数据目录。已有语言偏好会继续保留。

当前 Windows 构建尚未完成代码签名，SmartScreen 可能提示“未知发布者”。请仅从本项目
Releases 下载并核对 SHA-256。iThread 是独立社区项目，与 iThoughts 无隶属或背书关系。

## English

This update brings the recent interface, icon, Settings and language improvements to both Windows
installer and portable builds.

- Refreshed interface and vermilion seal-style icon across the library, editor and Windows app.
- One template library groups reusable structure templates and complete worked examples.
- Settings is available from the library's left navigation, the editor's gear button and `Ctrl+,`.
- Configure appearance, motion, high contrast, Alt-hold hints and delay, and wheel pan/zoom and speed.
- Fixed Left/Right arrows moving branches and dismissing the shortcut reference while Alt is held.
- First-launch desktop language follows the preferred Windows system language: Chinese selects
  Simplified Chinese; all other languages select English. Saved manual choices take priority.
  The web app follows browser language preferences; no IP-based location lookup is used.
- Updated bilingual About information with the iThread maintainer and upstream attribution.
- Retains offline editing, native `.ithread` saves, iThoughts `.itmz` import/export and local CLI automation.

### Download and upgrade

Use `iThread-0.6.1-Windows-x64-Setup.exe` or the no-install
`iThread-0.6.1-Windows-x64-Portable.exe`. Standalone CLI launchers and `SHA256SUMS.txt` are included.
Back up important maps before upgrading; do not delete the application data directory. Existing
language preferences are retained.

Windows builds are currently unsigned and may trigger an “Unknown publisher” warning in SmartScreen.
Download only from this project's Releases and verify SHA-256. iThread is an independent community
project, not affiliated with or endorsed by iThoughts.
