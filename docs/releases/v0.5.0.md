# iThread v0.5.0

这一版重点补齐“重要资料能否放心长期编辑”和 Windows 日常使用体验。

## 数据安全与 iThoughts 交换

- 编辑中的内容会额外写入短间隔恢复草稿。异常退出后，如果草稿比稳定存档更新，重新启动会
  让用户选择恢复或丢弃；正常保存完成后会自动清理旧草稿。
- 导出 `.itmz` 前显示兼容性报告，分别统计可保留的主题、备注、链接、内嵌资源、任务信息和
  关系线，并列出会转换、简化或无法带回 iThoughts 的内容。确认后才生成交换副本。
- 仍建议把 `.ithread` 作为日常编辑主文件，把 `.itmz` 作为与 iThoughts 交换的副本。

## Windows 11

- 同时生成可选择安装位置的 Setup 安装版和无需安装的 Portable 便携版。
- 安装版注册 `.ithread`、旧 `.mmst` 和 `.itmz` 文件关联；双击原生文件可直接打开。
- 桌面“打开”“另存为”、Ctrl+S 和后台自动保存使用受限文件令牌访问用户选择的文件，不向
  页面暴露绝对路径，也不能读取任意文件。
- 把 `.ithread` 放在 OneDrive、Dropbox、坚果云等系统同步目录即可选择性同步；检测到外部
  修改时会暂停静默覆盖并要求确认，软件本身仍可完全离线使用。
- “检查更新”会查询 GitHub Releases；只有用户点击操作按钮时才打开下载页，不会静默安装。

## 流畅度与界面

- 大型导图后台布局线程完成后保持热启动；选中、颜色、备注、任务状态、关系线等不改变几何
  结构的编辑会复用现有坐标，避免重复整图布局。
- 中文界面补齐开始页、检查器、搜索、对话框、可访问标签以及 HTML/SVG/演示导出中的文字。

## 下载与校验

安装版文件名为 `iThread-0.5.0-Windows-x64-Setup.exe`，便携版为
`iThread-0.5.0-Windows-x64-Portable.exe`。当前构建在代码签名完成前仍可能触发 SmartScreen，
请从项目 Releases 页面下载并核对同页 `SHA256SUMS.txt`。
