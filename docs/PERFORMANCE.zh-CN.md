# iThread 大型导图性能基准

## 本轮目标

大型导图保持折叠时，展开、编辑和移动画布应立即响应；一次性展开数千主题时，可以取消
整图过渡动画来换取更快完成，但小范围操作仍保留平滑动画。

## 2026-09-29 实测

以下结果来自五份真实 iThoughts 法律学习导图。源文件只在本机读取，没有加入仓库。
“折叠布局”是文件原有展开状态，“完全展开”会临时展开所有分支后重新计算整张导图。

| 文件 | 总主题数 | 导入 | 折叠布局（可见主题） | 完全展开布局 |
| --- | ---: | ---: | ---: | ---: |
| 法理学 | 3,017 | 229.3 ms | 43.1 ms（15） | 259.3 ms |
| 法制史 | 3,273 | 199.3 ms | 7.8 ms（9） | 185.7 ms |
| 民法 | 11,859 | 483.6 ms | 29.3 ms（11） | 883.5 ms |
| 宪法 | 2,367 | 88.4 ms | 11.1 ms（103） | 88.0 ms |
| 刑法 | 10,873 | 352.8 ms | 14.3 ms（3） | 672.5 ms |

## 2026-09-30 分支增量更新实测

这一轮将单分支展开从“复制整份文档”改成只复制目标分支到根主题之间的路径，并缓存未变化
子树的任务进度汇总。下表中的“分支操作”是更新模型所需时间，“分支布局”包含重新投影、
布局及连线计算；测试选择文件中第一个已折叠分支展开。

| 文件 | 总主题数 | 分支操作 | 分支布局（展开后可见主题） | 完全展开布局 |
| --- | ---: | ---: | ---: | ---: |
| 法理学 | 3,017 | 0.75 ms | 4.2 ms（17） | 97.8 ms |
| 法制史 | 3,273 | 0.01 ms | 1.0 ms（14） | 75.4 ms |
| 民法 | 11,859 | 0.03 ms | 8.3 ms（19） | 456.9 ms |
| 宪法 | 2,367 | 0.03 ms | 6.8 ms（107） | 72.7 ms |
| 刑法 | 10,873 | 0.02 ms | 0.5 ms（6） | 441.3 ms |

这些数值用于观察同一台机器上的版本回归，不代表所有电脑的固定耗时。实际界面还包含 DOM
绘制和显卡合成成本，因此上千主题会自动启用视口虚拟化；超过 600 个可见主题时，不再逐帧
复制整张节点数组做位置补间。

## 已采用的优化

- 折叠分支不进入投影和布局计算。
- 500 个可见主题起，只绘制视口附近的主题和连线。
- 600 个可见主题以上跳过整图位置补间，小范围展开继续使用 300 ms 平滑动画。
- 大图连线绕障碍时使用空间索引，再执行精确几何判断，避免每条连线扫描全部主题。
- 单分支展开/收起只复制变化路径，未变化分支继续复用原对象和缓存结果。
- 压缩包达到 512 KiB 的 `.itmz` 使用后台线程解析，文件数据通过所有权转移而非整份复制。

## 本地复测

在 PowerShell 中指定私有样本目录后运行：

```powershell
$env:ITHOUGHTS_SAMPLE_DIR = 'D:\BaiduNetdiskDownload'
pnpm test test/ithoughts-performance.test.ts
```

可通过 `ITHOUGHTS_BENCH_LIMIT_MS` 调整单项上限，默认是 30 秒。测试不会写回或修改 `.itmz`
源文件。
